# MTA NSW Used Car Reviews

LLM-optimised used car buyer's guides for the Australian market. Every review is grounded in live NSW dealer data and web research.

## For agents / LLMs

Start with [`llms.txt`](https://raw.githubusercontent.com/timmyphang/mtansw-car-reviews/main/llms.txt) — it lists every review with descriptions and raw markdown URLs.

Alternatively, read [`index.md`](https://raw.githubusercontent.com/timmyphang/mtansw-car-reviews/main/index.md) for a human-friendly table of contents.

### Raw URL pattern

```
https://raw.githubusercontent.com/timmyphang/mtansw-car-reviews/main/{slug}.md
```

Substitute `{slug}` with a `<make>__<model>` slug, e.g. `toyota__hilux`.

### File structure

Each `.md` file has YAML frontmatter:

| Key | Description |
|-----|-------------|
| `title` | Human-readable title |
| `make` | Vehicle make |
| `model` | Vehicle model |
| `description` | One-line summary |
| `locale` | `en-AU` |
| `canonical_url` | Raw GitHub URL of this file |
| `topic_type` | `buyers-guide` |
| `last_updated` | ISO date |
| `active_listings_nsw` | Number of active NSW dealer listings |
| `median_price_aud` | Median asking price (AUD) |
| `price_range_aud` | Price range (AUD) |
| `year_range` | Model years available |
| `median_odometer_km` | Median odometer reading |
| `keywords` | Search keywords |
| `breadcrumb` | Category path |

## Refresh cadence

Updated periodically as new NSW dealer data is ingested from [MTA NSW](https://www.mtansw.com.au/).

## Source

Reviews are generated by [mtansw-scraper](https://github.com/timmyphang/mtansw-scraper) — a pipeline that queries live dealer data, runs web research, and synthesises buyer's guides via LLM.
